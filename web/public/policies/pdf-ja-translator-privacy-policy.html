PDF日本語化ツール プライバシーポリシー

最終更新日: 2026年10月5日

PDF日本語化ツール（以下「本アプリ」）は、英語のPDFを開いて、段落ごとに日本語へ翻訳し、翻訳後のPDFを書き出すアプリです。 PDFの中身は、この端末の中で開いて処理します。開発者のサーバーにPDFや翻訳の内容を送ることはありません。アカウントも不要です。 翻訳のときだけ、段落の文章が、利用者ご自身の Anthropic（Claude API）のアカウントを使って送信されます（下記「3. 外部への送信」）。

1. 扱う情報と保存する場所

情報内容保存の場所・期間
開いたPDF 利用者が選んだPDFファイルのコピー（作業用） アプリの保存領域に置きます。次に別のPDFを開くと上書きされ、アプリを削除すると消えます。
翻訳の結果 段落ごとの日本語の訳文と、利用者が調整した文字の大きさ アプリを開いている間だけ、端末のメモリにあります。アプリを閉じると消えます。
書き出したPDF 翻訳を反映したPDF 利用者が選んだ保存先に保存されます。アプリの作業用に一時的なコピーを残すことがあり、次の書き出しで上書きされます。
Claude API のキー 利用者が入力したAPIキー この端末の中で、Android の鍵管理機能（Keystore）により暗号化して保存します。開発者には送られません。

2. 権限の使いみち

権限使いみち
インターネット翻訳のときに、段落の文章を Claude API（Anthropic）へ送り、訳文を受け取るため

PDFは、Android の標準のファイル選択画面で利用者が選んだものだけを読みます。端末内のほかのファイルや写真などには、アクセスしません。

3. 外部への送信

翻訳を実行すると、PDFから取り出した段落の文章（英語）が、Anthropic の Claude API（api.anthropic.com）へ送信されます。 同時に、利用者が登録したAPIキーが、その通信に付けられます。送られた文章は、Anthropic のプライバシーポリシーおよび利用者の API 契約に従って扱われます。

開発者（T-tech）のサーバーには、PDF・翻訳結果・APIキーのいずれも送信しません。アカウント登録も、広告も、利用状況の解析（アナリティクス）も、クラッシュ情報の収集もありません。 翻訳を行わず、PDFを開いて読むだけの場合は、外部への通信は発生しません。

4. 利用者が管理できること

  • APIキーは、アプリ内の「APIキー」から、いつでも登録し直せます。
  • 翻訳の結果は、アプリを閉じると消えます。書き出していない翻訳は、もう一度翻訳し直す必要があります。
  • 作業用に残っているPDFのコピーは、アプリのデータを消去するか、アプリを削除すると消えます。

5. 子どもの利用について

本アプリは、子どもから個人情報を集めることを目的としていません。

6. 改定

本ポリシーは、必要に応じて改定することがあります。改定後は本ページに掲示し、最終更新日を改めます。
