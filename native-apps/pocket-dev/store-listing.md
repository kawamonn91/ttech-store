# T-tech Store の掲載内容

`web/scripts/update-listing.mjs` と `publish-app.mjs` に渡す内容。アイコンは `store-icon.svg`（`set-app-icon.mjs`）、
スクリーンショットはエミュレーターで実際に使っている画面を撮って `add-screenshot.mjs` で載せる。

- 表示名: pocket-dev
- スラッグ: pocket-dev
- カテゴリ: tools（ツール）

## 短い説明

スマホ・タブレットで使う IDE とターミナル。Pocket Linux・自分のサーバー・SSH・Google ドライブのファイルを編集できます

## 説明

スマホ・タブレットでコードを書くための IDE とターミナルのアプリです。エディタは Monaco（VS Code と同じ部品）で、シンタックスハイライト・タブ・保存・コード整形に対応しています。PDF と画像のプレビューもできます。

■ つなぐ先
・Pocket Linux: 同じ端末の Pocket Linux のコンテナ（編集と実行）
・リモート: 自分の PC や VPS で動かす pocket-dev サーバー（編集と実行）
・SSH: SSH のサーバー（編集とシェル）
・Google ドライブ: Drive のファイルを直接編集（保存するとすぐ Drive に入ります。プログラムの実行はできません）

■ ターミナル
実際の PTY につながるので vim や top も動きます。Esc・Tab・Ctrl・矢印をソフトキーボード用の補助キーで入力できます。

■ 注意
・Google ドライブへのログインでは「このアプリは Google で確認されていません」と表示されます。個人で配布しているアプリのためです。「詳細」から「T-tech Pocket に移動」へ進んで許可してください
・Google ドライブの編集は 64 ビットの端末で使えます
・リモートで使うときは、PC 側で pocket-dev サーバー（Docker コンテナ）を起動し、表示されるアドレスとトークンを入力してください
